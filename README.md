# Social Sleuth 🔍

> **A Game-Based Learning Approach to Teaching Social Engineering, Data Privacy, and OSINT Principles at KS3 Level**

[![Live Demo](https://img.shields.io/badge/Live_Demo-Play_Social_Sleuth-blue?style=for-the-badge)](https://calzonepiccante.github.io/social-sleuth/)

## 📖 Project Overview
**Social Sleuth** is a browser-based, gamified educational tool developed as part of an undergraduate dissertation at **Lancaster University** (BSc Hons Computer Science). 

Designed specifically for **Key Stage 3 pupils (Years 7–9, ages 11–14)**, the game addresses statutory UK National Curriculum requirements around digital literacy, e-safety, and data privacy.

## 🎯 Educational Mechanics
Rather than relying on passive e-safety lectures, **Social Sleuth** uses a **Capture The Flag (CTF)** format:
- **Role Reversal:** Pupils adopt the persona of an Open Source Intelligence (OSINT) investigator.
- **Active Discovery:** Pupils analyze simulated public social media profiles, metadata, and overshared personal data to uncover security flags.
- **Pedagogical Goal:** By understanding how information is scraped and correlated from an attacker's perspective, pupils develop an intuitive understanding of why personal privacy settings and healthy online habits matter.

## 💻 Tech Stack
- **Frontend:** HTML5, CSS3, Modern JavaScript
- **Deployment:** GitHub Pages (Client-side, zero-install, works on standard school browser environments)
